# 业务规则

- 车辆业务客席集中配置：Alphard 6、Hiace 9、Hiace 13、25 座车辆 25。
- 分车始终采用 Sequential Fill（顺序装载）；先填满 Vehicle 1，再 Vehicle 2/3，既有车辆不会因后续订单升级车型。
- 80% 仅为内部装载目标，不作为对旅客展示的余位或服务承诺。
- 公共拼席与私人团体完全分开。
- 取消、退款、未出席不产生推荐奖励；只允许一层直接推荐。
- 未确认的价格、日期、余位、集合点和政策必须为空或显示“待公布”，不得推算或编造。
- 安全座椅、轮椅租赁、无障碍车辆、升降设备和工作人员协助的提交只代表需求进入审核；确认前不得显示为已提供或编造费用。
