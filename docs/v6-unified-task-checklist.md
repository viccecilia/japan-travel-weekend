# V6 / V6.1 统一整改任务清单

统一推广规则：司导与游客推广大使均按符合资格订单的 10% 计算现金佣金；新人只认首笔有效且已完成行程的订单；行程完成后才解锁佣金；每周只允许发起一次提现。任何历史订单、已产生收益和不可变订单快照不得被新规则覆盖或重算。

## 01. 支付与结账恢复（P0）

- [x] 持久化 checkout attempt、报价、幂等键及当前结果。
- [x] 报价过期或后台改价后可重新报价、明确二次确认并继续付款。
- [x] 刷新、响应丢失、草稿已转换、已有支付意图、银行转账及零元订单均可幂等恢复。
- [x] 已成功订单永不因重试被取消；库存和 Payment Intent 不重复。
- 验收：AT01–AT06；游客结账页、服务端接口、数据库状态三方一致。
