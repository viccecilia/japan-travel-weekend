# 乘客资料与特殊乘车需求

特殊乘车需求属于订单私有履约数据，仅订单本人、授权运营人员及确有必要的本车工作人员可见。普通 Vehicle Group 乘客只能看到订单人数等公共字段，不得看到儿童年龄、安全座椅、婴儿车、轮椅、行动协助、服务犬或其他家庭说明。数据只保存在当前会话；正式服务必须由受控后端保存并审计访问。

## 儿童与婴儿车

儿童人数为 0 时不显示儿童模块，也不创建儿童资料。大于 0 时按人数收集年龄；身高和体重仅预留字段，当前不收集。安全座椅支持平台提供、自带、不需要、需人工联系；平台提供数量不得超过儿童人数，状态为“已提出／确认中”，绝不表示租赁成功。婴儿车记录是否携带、数量、能否折叠和是否大型，作为配车空间条件。

## 轮椅与行动协助

轮椅模块独立于儿童。记录自带／申请租赁、手动／电动、折叠性、可选尺寸和重量、能否转移到车辆座椅，以及升降设备、无障碍车辆和工作人员协助需求。申请租赁或设备协助均需运营确认，不能承诺一定提供。不收集无关健康诊断。

## 其他条件与状态

结构还覆盖大件行李、助行器、折叠设备、服务犬、减少步行的集合方式和其他履约说明。统一状态包括：未提出、已提出／确认中、已确认、自带、不需要、需人工联系、无法提供。运营接口通过 `toOperationsConditions` 获取配车条件；本阶段不实现车辆适配算法，Sequential Fill 保持不变。
