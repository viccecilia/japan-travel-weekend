# 正式产品基础

集中配置管理语言、运行模式、种子开关、车辆客席、Trip Room 开放规则、位置时长、80% 内部目标、外部能力状态与功能开关。UI 经 `TravelRepository` 和 `TravelService` 读取业务数据，当前使用内存实现，后端 API 可替换此入口。

正式数据与 UI 偏好分离：`localStorage` 只保存紧凑显示等偏好；账户、订单、乘客隐私、位置与消息不得长期保存在浏览器。尚未连接的真实能力包括认证、库存、支付、地图、GPS、聊天、通知与后端 API。

品牌继续使用深蓝、暖金、白和灰。移动端以 320/375 为底线，底部导航预留安全区；发布前必须继续保持 noindex，并完成真实后端、支付、安全、法律和无障碍验收。
