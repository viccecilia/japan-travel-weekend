# 配车与 Trip Room 履约基础

`FulfilmentService` 将已确认订单转换为顺序装载计划、Vehicle Assignment 和一车一群的 Vehicle Group。特殊乘车需求通过运营条件投影进入未来配车审核，但本阶段不自动选择车型；运营必须在确认辅助设备与空间后完成配车。

乘客只能读取自己被分配的车辆群组。司机／司导必须有本车 Staff Assignment；只有标记为履约必要的工作人员才能读取订单辅助需求。普通乘客永远不能读取其他家庭的需求。

Trip Room 在 opensAt 前为 frozen，只读展示履约信息；达到开放时间后才切换 open。生产后端必须以服务端时间执行转换和权限校验，客户端状态不能作为授权依据。
