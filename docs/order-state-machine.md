# 订单状态机

支付前新增独立草稿状态：`payment_not_started → pending_manual_review / converted / expired / cancelled`。`payment_not_started` 不是正式订单、不是库存锁、不是支付成功；只有后续服务端重新校验价格、库存和辅助服务后，才能转换为 `orders.pending_payment`。

主链路：待支付 → 处理中 → 已支付 → 已确认 → 待登车 → 已登车 → 已完成。

终止或补偿状态：待支付可变为已过期或已取消；已支付／已确认可按政策变为已取消或已退款。支付回调必须幂等，客户端不能自行宣告支付成功。只有后端确认的订单可以生成有效登车凭证，只有运营确认“已完成”才可结算奖励。

订购成功页必须显示订单号、成功状态和“立即查看我的行程”，并在 3 秒后自动前往本订单详情；不得自动进入登车凭证。订单详情是订购后履约入口，未确认的日期、时间、地址、车辆、工作人员、金额和地图信息保持为空并显示明确更新说明。
