# Vehicle Group 聊天翻译

聊天翻译以每位账户自己的目标语言为准，不改变其他成员的界面。浏览器通过 `navigator.languages` 读取手机首选语言，并映射为简体中文、日语、英语、越南语或尼泊尔语；不支持的系统语言回退英语。用户可以关闭“跟随手机”并手动选择，也可以关闭自动显示译文。

数据库始终保存原文、原始语言和可选模板键。译文按 `message_id + target_language` 分别缓存，不能覆盖原文。普通乘客只可读取本车消息的译文；个人翻译偏好只允许本人读写；译文写入和翻译上下文函数只授予 service role。司机的重要模板保存中文原文和模板键，客户端可立即展示五语预置译文；预置译文仍需母语运营人员在正式上线前审核。

自由聊天通过后端 `/v1/translations/message` 请求。服务端先验证 Supabase Bearer 会话，再由数据库确认账户属于该 Vehicle Group，缓存命中时不再次调用供应商。未授权返回拒绝；供应商未启用返回不可用，并保留原文。浏览器永远不接触翻译 API 密钥。

Google Cloud Translation 适配器已经实现，但默认 `JTW_TRANSLATION_ENABLED=false`，且没有 `GOOGLE_TRANSLATION_API_KEY` 时不可用。本轮不启用付费翻译、不产生费用。启用前必须批准供应商费用、数据处理条款、日志与保留策略、速率限制、每账户／每行程预算和预置模板母语审核。照片、位置、电话、特殊需求原文与登车凭证不发送给翻译供应商。

迁移 `202608260020_chat_translation_preferences.sql` 增加个人偏好、多语言缓存、模板键、来源语言和受限服务函数。该迁移已在 Supabase 测试项目顺序执行一次；结构查询确认两张表、模板字段、个人偏好 RPC 与服务端权限边界存在，虚构乘客账户也已验证只能读写自己的偏好。自由聊天在付费供应商未启用时仍保留原文并明确提示译文暂不可用。
