# JTW 共通ルール体系 V1.0
## 日本語版

# A. JTW 旅行共通ルール V1.0

## 1. 特別な配慮が必要な方・安全に関するご案内

1. **70歳以上の方、妊娠中の方、乳幼児が参加する場合は、成人のご家族または成人の同行者が全行程を通して付き添ってください。**

2. 18歳未満の方は単独で参加できません。成人の保護者または成人の同行者が全行程を通して付き添ってください。

3. 高齢の方、妊娠中の方、歩行に不安のある方、心血管系の疾患その他旅行の安全に影響する可能性のある健康上の事情がある方は、ご自身の体調を踏まえ、参加に適した旅行行程かどうかを慎重にご判断ください。

4. 特別な介助、歩行補助、その他通常の参加に影響する事情がある場合は、予約前にスタッフへお知らせください。参加予定の行程が適しているか確認いたします。

5. 同行者は、同行する方の年齢、体調、行動能力に応じて必要な見守り・介助を行ってください。乗務・案内スタッフはツアー全体の運営および現地での調整を担当しており、継続的な個人介助、抱きかかえ、医療的ケア、一対一の付き添いを行うことはできません。

6. 行程中、現地の環境や参加者の状態から、特定の活動を続けることに明らかな安全上の懸念があるとスタッフが判断した場合、安全を優先し、その活動への参加を控える、または中止するようお願いすることがあります。

7. 参加者ご本人の体調、現地での安全上の案内に従わなかったこと、または同行者による見守り・介助が不十分であったこと等により発生した医療費、救急対応費、追加交通費その他の個人的費用は、原則として参加者ご本人の負担となります。

## 2. お子様の参加・料金について

1. **2歳未満の乳幼児は、単独で座席を使用せず、同行する成人の方が対応する場合、無料で参加できます。**

2. **2歳以上のお子様は1席を使用し、料金は大人と同額となります。**

3. 2歳未満であっても単独座席を希望する場合は、通常の1席分の料金が必要です。

4. チャイルドシートその他特別な対応が必要な場合は、予約時に事前にお知らせください。車両および当日の運行状況に応じて手配いたします。

## 3. 料金に含まれるもの

各商品ページに別途記載がない限り、通常以下が含まれます。

1. 行程ページに記載された車両サービス料金。
2. 行程車両にかかる燃料費および道路通行関連費用。
3. 行程に記載された乗務・案内サービス料金。
4. 商品ページに「含まれる」と明記されているその他のサービス。

車両は、当日の参加人数、ルートおよび運行状況に応じて運営側が手配します。**特定車種の指定・確約は行いません。**

## 4. 料金に含まれないもの

商品ページに明記がない限り、以下は通常含まれません。

1. 朝食、昼食、夕食その他の個人的な飲食費。
2. 観光施設の入場料および現地で任意参加する有料プログラム。
3. 個人的な買い物その他の私的支出。
4. 行程外で個人が利用する交通費。
5. 参加者個人の事情により発生する医療費、救急対応費、追加宿泊費、追加交通費等。
6. 「料金に含まれるもの」および商品ページに明記されていないその他の費用。

## 5. 集合・出発前後のご連絡

1. 本商品は指定場所に集合して出発します。**ホテルや宿泊施設への送迎サービスはありません。**

2. 注文画面および出発案内に記載された集合場所・集合時間に、時間どおりお越しください。

3. 集合場所、集合時間、出発時間は、注文画面および出発前に送信される最新の案内を基準とします。

4. 出発当日は、予約時に登録した携帯電話および普段利用している連絡手段を受信可能な状態にしてください。集合、行程変更その他重要な連絡に使用します。

5. 天候、道路規制その他の運行上の事情により集合情報を変更する必要がある場合は、注文メッセージ、システム通知、または登録済みの連絡先を通じて、可能な限りご案内します。

## 6. 行程に関するルール

1. 本商品は複数のお客様が参加する固定行程の旅行です。各観光地で指定された集合時間を守り、乗務・案内スタッフの現地での指示にご協力ください。

2. 実際の移動時間、観光時間、滞在時間は当日の運行状況によります。

3. ツアー全体を円滑に実施するため、道路、天候、混雑、施設の運営状況その他現地の事情に応じて、観光地を回る順番や滞在時間を合理的に調整する場合があります。

4. 行程中は、立入禁止区域への無断立入り、柵を越える行為、その他明らかに危険を伴う行為を行わないでください。

5. ご自身の判断で途中離団または行程を中止する場合は、事前にスタッフへお知らせください。未利用の後続サービスについては、その注文に適用される旅行条件および取消規定に従って取り扱います。

6. 他の参加者の安全を脅かす行為、重大な迷惑行為、安全上必要な指示への拒否、泥酔による制御不能その他行程の安全・正常な実施に著しく影響する行為がある場合、運営側は状況に応じて必要な安全措置を講じることがあります。

## 7. 天候・交通・不可抗力

台風、豪雨、大雪、強風、地震、洪水、火山活動、重大な交通事故、道路閉鎖、深刻な渋滞、公共交通機関の異常、政府・関係機関による規制、観光施設の臨時休業、突発的な社会事象その他合理的に管理できない事情により、予定していた行程に以下の変更が生じる場合があります。

- 行程の遅延
- 観光地の順番変更
- 滞在時間の短縮
- 交通手段の変更
- 一部施設・プログラムへの参加不可
- 行程の一部変更または取消

このような場合は、**参加者の安全、運転の安全、ツアー全体の実施可能性**を優先し、当日の状況に応じて合理的に調整します。

行程の取消、変更、返金その他の取扱いは、**予約時に適用される旅行条件、取消規定、実際に提供済み・未提供となったサービスの内容**に基づいて判断します。

## 8. 観光施設・第三者運営サービス

一部の観光施設、遊覧船、ロープウェイ、観光列車、温泉、ショー、アトラクションその他のサービスは、第三者により独立して運営されています。

営業時間、運行状況、販売状況、サービス内容は、天候、設備点検、現地規制、混雑等により予告なく変更または停止されることがあります。

第三者施設が一時的に利用できない場合、スタッフは当日の状況に応じて関連する行程を合理的に調整します。

## 9. 季節景観・自然条件

桜、紅葉、積雪、花の見頃、夕日、夜景の視界その他の自然景観は、気温、降雨、風その他の自然条件の影響を受けます。

商品ページの写真や紹介はルートおよび旅行体験をイメージしていただくためのものであり、**特定日の開花状況、紅葉の進み具合、積雪量、天候、景観状態を保証するものではありません。**

自然条件が見頃の最盛期に達していない場合でも、原則として通常どおり催行します。

## 10. お荷物について

1. 本商品は観光行程のため、大型荷物の持参は原則としておすすめしていません。

2. 大きな荷物または多数の荷物を持参する必要がある場合は、予約時に事前にお知らせください。

3. 搭載可能な荷物の数量・サイズは、車両スペース、当日の参加人数、安全上の条件により制限される場合があります。

4. 事前申告のない大型・過剰な荷物は、当日の車両で安全に積載できない場合、持ち込めないことがあります。

## 11. 食事・食品について

1. 商品ページに明記がない限り、本商品に食事は含まれません。

2. 自由時間中または各自で食事をする場合は、レストラン、観光施設、関連施設のルールを守ってください。

3. 店舗によっては、外部からの飲食物の持ち込みや、注文せずに座席のみ利用することを認めていない場合があります。

4. 食物アレルギー、宗教上の食事制限、その他特別な食事上の要望がある場合は、レストランおよび食品の情報をご自身でご確認ください。スタッフは合理的な範囲で案内・コミュニケーションをお手伝いできますが、すべての店舗・食品が特別な食事要望に完全対応できることを保証するものではありません。

## 12. 貴重品・所持品

パスポート、現金、クレジットカード、携帯電話、カメラその他の貴重品はご自身で適切に管理してください。

自由時間、観光、集合、移動の際には、忘れ物・盗難・破損を防ぐため、随時ご自身の所持品をご確認ください。

紛失が判明した場合はスタッフが必要な範囲でお手伝いしますが、発見・返還を保証することはできません。

## 13. 健康上の緊急事態

旅行中に急病、けが、その他の健康上の緊急事態が発生した場合、スタッフは合理的な範囲で現地の医療機関、救急機関、緊急連絡先への連絡を支援します。

医療・安全対応を優先する必要がある場合、当該参加者およびツアー全体の行程を調整することがあります。

個人の健康状態に起因する医療費、救急対応費、薬代、追加交通費、宿泊費等は、原則として参加者ご本人の負担となります。

## 14. 現地法令・公共秩序

行程中は、日本の法令、交通ルール、観光施設の規則、公共秩序を守ってください。

日本法で禁止・制限されている物品を持ち込まないでください。また、ご自身、他の参加者、スタッフ、公共の安全を脅かす行為を行わないでください。

現地の文化・習慣および宗教施設の参拝・見学ルールを尊重してください。

## 15. 安全上のご案内

ご自身の体調と現地環境を踏まえ、無理のない範囲でご参加ください。

海上活動、遊覧船、雪上、温泉、山間部、階段、滑りやすい路面その他一定の危険を伴う場所・活動では、現地スタッフ、乗務・案内スタッフ、施設運営者の安全上の指示に従ってください。

天候、設備、道路その他安全上の理由から、スタッフが活動の中止・終了・変更を求めた場合はご協力ください。

季節およびルートに応じて、歩きやすい靴・服装、日焼け対策、防寒・雨具等、必要な装備をご準備ください。

## 16. 行程後の交通手配

商品ページに記載された帰着・終了時間は予定時刻です。

道路交通、天候、施設運営等には不確定要素があるため、**予定終了時刻の直後に変更・振替が難しい重要な交通機関を設定することはおすすめしません。** 例：国際線、新幹線、長距離バス等。

ご自身で後続の交通を手配する場合は、十分な時間的余裕を確保してください。

## 17. ルールおよび注文バージョン

本共通ルールは、運営、安全、サービス上の必要に応じて更新される場合があります。

まだ予約が完了していない商品については、現在正式に公開されているバージョンが適用されます。

すでに成立している注文については、原則として、**予約時に表示・適用されていたルート内容、集合情報、ルート固有の注意事項、共通ルール、サービス時間ルール、取消規定の各バージョン**を基準とします。

予約後に天候、交通、施設の臨時変更等により実際の運行調整が必要となった場合は、注文通知、システムメッセージその他適切な方法でご案内します。

後日ルールが更新されても、すでに成立した注文に適用されるルールバージョンが自動的に置き換わることはありません。

# B. JTW 標準10時間サービス時間モジュール V1.0

## 行程サービス時間

本商品は約 **10時間以内** で実施する旅行行程です。運転の安全、乗務・案内スタッフの勤務体制、およびツアー全体を円滑に完了するため、**原則として予定されたサービス時間を超える延長サービスは行いません。**

交通渋滞、天候、祝祭日、混雑、道路状況、観光施設の運営状況等により、当日の実際の行程時間が当初の予定と異なる場合があります。

全体の行程が標準サービス時間を超える可能性があると判断される場合、スタッフは **安全な帰着およびツアー全体の円滑な実施** を優先し、当日の状況に応じて **観光地を回る順番、自由時間、各観光地の滞在時間を合理的に調整** します。

商品ページに記載された到着時刻および滞在時間は予定の目安であり、**実際の運行状況を優先します。**

### 商品ページ用短縮表示

> **本行程は約10時間以内の旅行です。交通、天候、現地運営状況により観光順序や滞在時間を調整する場合があります。原則として延長サービスは行いません。**

# C. JTW 標準24時間取消規定 V1.0

## 取消・返金規定

1. **出発時刻の24時間前までに取消申請を行った場合、支払済み行程料金の100％を返金します。**

2. **出発時刻の24時間以内に取消申請を行った場合、返金は行いません。**

3. **行程開始後の取消、または参加者ご本人の事情により行程に参加できなかった場合、返金は行いません。**

取消申請の時刻は、システムが実際に申請を受信・記録した時刻を基準とします。

注文成立後、その注文に適用される取消・返金規定およびそのバージョンは保存されます。後日取消規定が変更されても、すでに成立した注文の適用条件が自動的に変更されることはありません。
