# 库存、订单与支付基础

`InventoryProvider`、`PaymentProvider` 与 `OrderService` 构成可替换边界。本地 sandbox 实现库存锁、幂等支付授权、订单确认、取消和退款；它不调用真实商户、不处理银行卡，也不代表生产支付成功。

正式流程为：锁定 Departure 座位 → 使用幂等键请求支付 → 成功后提交库存锁并确认订单；失败时释放库存。退款通过原 paymentId 执行。生产接入必须补充锁过期回收、数据库事务、支付签名回调、金额与币种服务端校验、重放防护、对账、退款权限和审计。

当前价格仍未确认，本地流程只允许金额 0 的开发验证。没有商户账户、Webhook 密钥和运营退款政策时，production 支付继续保持未连接。
